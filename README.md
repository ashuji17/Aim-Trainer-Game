# Aim-Trainer-Game
Developed an interactive aim training game using Pygame, implementing a real-time game loop with event-driven architecture.
<br>
Implemented performance tracking metrics including reaction speed (targets/sec), accuracy, hits, and survival-based lives system.
<br>
Designed dynamic target system with randomized spawning, growth–shrink mechanics, and collision detection using geometric calculations.
<br>
Built responsive UI with live HUD (timer, score, speed, lives) and end-screen analytics for user performance evaluation.
<br>
Optimized gameplay responsiveness with controlled frame rate (60 FPS) and efficient object lifecycle management.
<br>
Applied modular design using object-oriented programming (Target class) to encapsulate behavior and improve code maintainability.
